This page needs to be served over HTTP

You opened this file directly from disk (). Browsers block API requests from file:// pages for security, so nothing here will work correctly.

Instead, run a local server from the frontend/ folder and open it over http://:

cd frontend
python3 -m http.server 5500

Then open http://localhost:5500 in your browser.

Finding funding isn't just searching a database — GrantSetu continuously discovers live opportunities from Grants.gov, NGOBox and other sources, ranks them against your NGO's profile with an explainable score, lets you search in plain language, and gives you interactive analytics to understand the funding landscape.
